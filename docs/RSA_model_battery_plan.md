## The design these models sit on

40 conditions = **2 species-shown** (Dog / Hum — the agent in the video) ×
**5 emotions** (P=Positive anticipation, H=Happiness, A=Anger, F=Fear, N=Neutral) ×
**4 exemplars** (1–4). Condition labels: `DogP1 … HumN4`.

Cell values in a model matrix: `0` predicted-same · `0.5` predicted-intermediate ·
`1` predicted-different · `NaN` pair excluded from the RSA correlation. Diagonal = 0.
The 4 exemplars within an emotion×species cell are treated as the same condition (0).

**One model serves both brains.** The matrix is over stimulus conditions, so the same
csv is correlated against the dog-brain (`--specie D`) and human-brain (`--specie H`)
neural dissimilarity structure. The battery is therefore run twice (D and H), not rebuilt.

## The two design levers

**1. The emotion hypothesis** — what the brain is predicted to represent as similar:

| Hypothesis | Rule | Uses |
|---|---|---|
| `emo-id` | 5-way emotion identity (same emotion = 0) | the canonical category model |
| `val3` | valence 3-class: {P,H}pos / {A,F}neg / {N}neu | broad affective structure |
| `val-bin` | positive vs negative (Neutral excluded) | clean valence contrast |
| `emo-vs-neu` | any emotion vs Neutral | "is there an emotion signal at all" |
| `threat` | {Anger,Fear} vs rest | threat / defensive system |
| `approach-avoid` | {P,H} vs {A,F} (Neutral excluded) | motivational direction |
| `grad-val` | graded valence axis pos→neu→neg (0 / 0.5 / 1) | continuous valence |
| `grad-arousal` | graded arousal {A,F}=high, {P,H}=mid, {N}=low | continuous arousal |

**2. The agent-species treatment** — how each hypothesis treats the Dog/Hum-shown axis:

| Treatment | Which pairs are scored | Question it answers |
|---|---|---|
| `collapse` | all pairs, agent ignored | agent-invariant emotion representation |
| `within` | Dog–Dog & Hum–Hum only | emotion structure within each agent species |
| `cross` | Dog–Hum only | **abstract** emotion that generalizes across agent species |
| `dog` | Dog block only | emotion structure for dog-shown stimuli alone |
| `hum` | Hum block only | emotion structure for human-shown stimuli alone |

8 hypotheses × 5 treatments = **40 models**, plus **`agent-species-id`** (Dog-shown vs
Hum-shown, emotion ignored) = **41**.

The `cross` treatment is the scientifically richest cell: a significant fit there means the
region encodes the emotion *independently of whether a dog or a human displays it* — the
strongest form of the cross-species emotion-representation claim, testable in both brains.

## Assumptions baked in (edit `build_rsa_models.py` to change)

- **Valence axis order:** positive {P,H} → neutral {N} → negative {A,F}; adjacent classes
  0.5, opposite 1.0.
- **Arousal ranks:** threat emotions {A,F}=high, positive {P,H}=mid, {N}=low. (No
  per-stimulus arousal ratings were used; this is the ordinal assumption. Swap in measured
  ratings if available.)
- **Neutral** is excluded (NaN) from `val-bin` and `approach-avoid`.

## How to run / schedule

Schedule one model across both brains (default `--specie both` = H and D):

```powershell
& "C:\ProgramData\anaconda3\python.exe" schedule_rsa.py `
    --dataset EmoC --model basic-block --rsa_model emo-id__cross
```

Schedule the **whole battery** (41 models × {D,H}). Fast-test settings shown; drop
`--reps/--reps_group` for full runs:

```powershell
$models = Get-ChildItem "P:\userdata\raulh87\data\EmoC\rsa_models\*__*.csv" |
          ForEach-Object { $_.BaseName }
foreach ($m in $models) {
    & "C:\ProgramData\anaconda3\python.exe" schedule_rsa.py `
        --dataset EmoC --model basic-block --rsa_model $m `
        --reps 100 --reps_group 1000 --z_threshold 3.1
}
& "C:\ProgramData\anaconda3\python.exe" run_jobs.py --max_jobs 0 --loop
```

Note: steps 0–1 (beta maps, pairwise similarity) are **model-independent** and shared
across the whole battery — they run once per species, then every model reuses them, so 41
models is far cheaper than 41× the full pipeline.

## Regenerating / extending

```powershell
& "C:\ProgramData\anaconda3\python.exe" build_rsa_models.py            # write all 41
& "C:\ProgramData\anaconda3\python.exe" build_rsa_models.py --dry-run  # preview + stats
```

Add a hypothesis → extend `BASE_RULES`; add an agent treatment → extend `TREATMENTS`.
All models are validated to have non-zero variance (a flat matrix can't be correlated).
